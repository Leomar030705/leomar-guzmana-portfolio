# Leomar Guzmana Portfolio

Static three-page portfolio ready for Vercel.

## Files
- `index.html` — Home / Personal Branding
- `skills.html` — Key Skills Inventory
- `goals.html` — Career Goals Portfolio
- `css/style.css` — Shared responsive styling
- `js/script.js` — Mobile navigation + dynamic footer year

## Deploy to Vercel
1. Upload the folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use the default settings for a static site.
4. Deploy.

No build command is required.
